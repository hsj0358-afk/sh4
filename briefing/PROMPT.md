## 0. 목표

HR(People)과 HRD의 **최신 트렌드와 사례**를, 실무자가 월요일 아침에 바로 읽고
**그날 발표까지 할 수 있도록** 정리한다.

- 초점: **국내(한국) + 글로벌 균형**
- 깊이: **상세 리포트** (읽는 데 10~15분)
- 관점: 모든 항목을 **경영진 · 직무전문가(현업) · 직원(HR의 고객)** 세 관점으로 조명
- 산출물: (1) 강의자료 슬라이드 아티팩트, (2) 이메일, (3) 아카이브 마크다운

## 1. 리서치 절차

4개 주제 각각에 대해 **최근 1~2주 우선**으로 국내·글로벌 자료를 찾는다.

1. **HR(피플) 트렌드** — 조직문화, 인재확보/리텐션, 피플 애널리틱스, 보상·평가, EX
2. **HRD · L&D** — 교육·역량개발, 리더십 개발, 리스킬링/업스킬링, 학습문화
3. **HR 테크 & AI** — HR 자동화, AI 도입, HR SaaS/솔루션 동향
4. **기업 사례 & 정책** — 실제 기업 도입 사례, 노동·인사 관련 제도/정책 변화

방법:
- `WebSearch`로 한국어·영어 쿼리를 **병행**한다.
  (예: `"2026 HR 트렌드 국내"`, `"employee experience trends 2026"`,
  `"리스킬링 사례 대기업"`, `"L&D AI 2026"`)
- WebSearch는 US 기반이라 국내 자료가 약하면, 한국어 쿼리 결과의 링크를
  `WebFetch`로 직접 열어 원문·날짜를 확인해 보완한다.
- 각 주제당 국내 1건 이상 + 글로벌 1건 이상을 확보하려 노력한다.

품질 규칙:
- **출처 URL은 항목마다 필수.** 날짜를 확인하고, 가급적 최신 자료를 쓴다.
- 광고성·저품질·출처 불명 자료는 배제한다.
- **근거 없는 수치·사례·기업명을 지어내지 않는다.** 확인 못 한 것은 그렇게 표기한다.
- 오래된(1년 이상) 자료는 "배경" 맥락으로만 쓰고 최신 트렌드로 오인하지 않는다.

## 2. 작성 규칙

- 언어: **한국어**. 전문 용어는 필요 시 영어 병기.
- 형식: `briefing/TEMPLATE.md`를 그대로 따른다.
- 각 항목 구조: **요약 → 관점별 시사점(경영진/직무전문가/직원) → 국내 적용 포인트 → 출처**
  - **경영진 관점**: 비용·리스크·전략·성과 지표 측면의 함의
  - **직무전문가(현업) 관점**: 실제 업무·역량·프로세스에 미치는 변화
  - **직원(HR의 고객) 관점**: 경험·성장·동기·수용성 측면의 체감 효과
- 마지막에 **이번 주 실행 제안** 3~5개, 각 제안에 대상 관점 태그(`[경영진]`/`[현업]`/`[직원]`)를 붙인다.

## 3. 산출물 생성

### (1) 강의자료 슬라이드 아티팩트  ← 핵심
브리핑 내용을 **바로 발표 가능한 슬라이드 덱**으로 발행한다.
- 발행 전 `artifact-design` 스킬을 로드해 디자인 품질을 맞춘다.
- 자체 완결형 HTML 1개(외부 리소스 금지, CSP 준수). 슬라이드 = 전체 화면 섹션.
- CSS `scroll-snap` + 인라인 JS로 **←/→ 키보드 넘김**, 진행 바, 페이지 번호.
- 라이트/다크 테마 모두 대응.
- 슬라이드 구성:
  1. 표지(제목 + 날짜/주차)
  2. 아젠다(4개 주제)
  3. 이번 주 한눈에(TL;DR)
  4~N. 주제별 슬라이드 — 항목마다 **경영진/직무전문가/직원 3분할 카드** + 하단 출처
  N+1. 이번 주 실행 제안(관점 태깅)
  마지막. 참고자료 링크 목록
- 밀도: 슬라이드당 핵심 3~5줄, 큰 제목, 카드형 레이아웃(발표용).

### (2) 이메일 (Gmail)
- 수신: `hsj0358@gmail.com`
- 제목: `HR·HRD 주간 브리핑 — YYYY.MM.DD`
- 본문: **이번 주 한눈에(TL;DR)** + 주제별 한 줄 요약 + **아티팩트 링크** + 실행 제안 요약
  (가독성을 위해 `htmlBody`로 서식 있는 본문 작성)
- **발송 방식**: 현재 연결된 Gmail 커넥터는 `create_draft`(초안 생성)만 지원하고

  준비 완료를 알린다(사용자가 초안에서 원클릭 발송).
- 향후 **발송 가능한 커넥터**가 연결되면 이 단계를 '초안 생성'에서 '자동 발송'으로 전환.

## 0. 목표

HR(People)과 HRD의 **최신 트렌드와 사례**를, 실무자가 월요일 아침에 바로 읽고
**그날 발표까지 할 수 있도록** 정리한다.

- 초점: **국내(한국) + 글로벌 균형**
- 깊이: **상세 리포트** (읽는 데 10~15분)
- 최신성: **최근 1주일(발행일 기준 직전 7일)의 소식·발표·사례 위주**로 리포팅.
  근거자료(통계·리서치·리포트)는 기간·범위를 더 넓게 활용해도 된다.
- 관점: 모든 항목을 **HR전문가(실무) · 경영진** 두 관점으로 조명
- 산출물: (1) 강의자료 슬라이드 아티팩트, (2) 이메일, (3) 아카이브 마크다운

## 1. 리서치 절차

4개 주제 각각에 대해 **최근 1주일 내 소식 위주**로 국내·글로벌 자료를 찾는다.
(헤드라인이 되는 사건·발표·발간물은 직전 7일 이내를 우선하고, 그 해석을 뒷받침하는
근거자료는 더 오래된 리서치·통계도 자유롭게 인용하되 발행 시점을 명시한다.)

1. **HR(피플) 트렌드** — 조직문화, 인재확보/리텐션, 피플 애널리틱스, 보상·평가, EX
2. **HRD · L&D** — 교육·역량개발, 리더십 개발, 리스킬링/업스킬링, 학습문화
3. **HR 테크 & AI** — HR 자동화, AI 도입, HR SaaS/솔루션 동향
4. **기업 사례 & 정책** — 실제 기업 도입 사례, 노동·인사 관련 제도/정책 변화

방법:
- `WebSearch`로 한국어·영어 쿼리를 **병행**한다. 최근성 확보를 위해
  "this week", "최근", 월 이름 등 시점 키워드를 섞어 검색한다.
  (예: `"HR 뉴스 이번 주"`, `"HR news July 2026"`, `"리스킬링 발표 사례"`)
- WebSearch는 US 기반이라 국내 자료가 약하면, 한국어 쿼리 결과의 링크를
  `WebFetch`로 직접 열어 원문·날짜를 확인해 보완한다.
- 각 주제당 국내 1건 이상 + 글로벌 1건 이상을 확보하려 노력한다.

품질 규칙:
- **출처 URL은 항목마다 필수.** 게시 날짜를 확인한다.
- **헤드라인 항목은 직전 7일 이내 자료를 우선**한다. 7일 내 자료가 부족한 주제는
  가장 최신 자료를 쓰되 날짜를 명시해 "이번 주 소식"으로 오인되지 않게 한다.
- 근거자료(통계·리서치·연구·과거 사례)는 기간 제한 없이 활용 가능 — 발행 시점 명시.
- 광고성·저품질·출처 불명 자료는 배제한다.
- **근거 없는 수치·사례·기업명을 지어내지 않는다.** 확인 못 한 것은 그렇게 표기한다.

## 2. 작성 규칙

- 언어: **한국어**. 전문 용어는 필요 시 영어 병기.
- 형식: `briefing/TEMPLATE.md`를 그대로 따른다.
- 각 항목 구조: **요약 → 관점별 시사점(HR전문가/경영진) → 국내 적용 포인트 → 출처**
  - **HR전문가(실무) 관점**: HR 실무·프로세스·제도 설계, 필요한 역량, 구성원 경험에 미치는 함의
  - **경영진 관점**: 비용·리스크·전략·성과 지표 측면의 함의
- 마지막에 **이번 주 실행 제안** 3~5개, 각 제안에 대상 관점 태그(`[HR전문가]`/`[경영진]`)를 붙인다.

## 3. 산출물 생성

### (1) 강의자료 슬라이드 아티팩트  ← 핵심
브리핑 내용을 **바로 발표 가능한 슬라이드 덱**으로 발행한다.
- 발행 전 `artifact-design` 스킬을 로드해 디자인 품질을 맞춘다.
- `Artifact` 도구가 없는 세션이면: `SendUserFile`(display: render)로 HTML을 전송하고,
  이메일 링크는 저장소의 `briefing/archive/YYYY-MM-DD.html` GitHub 링크로 대체한다.
- 자체 완결형 HTML 1개(외부 리소스 금지, CSP 준수). 슬라이드 = 전체 화면 섹션.
- CSS `scroll-snap` + 인라인 JS로 **←/→ 키보드 넘김**, 진행 바, 페이지 번호.
- 라이트/다크 테마 모두 대응.
- 슬라이드 구성:
  1. 표지(제목 + 날짜/주차)
  2. 아젠다(4개 주제)
  3. 이번 주 한눈에(TL;DR)
  4~N. 주제별 슬라이드 — 항목마다 **HR전문가/경영진 2분할 카드** + 하단 출처
  N+1. 이번 주 실행 제안(관점 태깅)
  마지막. 참고자료 링크 목록
- 밀도: 슬라이드당 핵심 3~5줄, 큰 제목, 카드형 레이아웃(발표용).

### (2) 이메일 (Gmail) — 목표: 완전 자동 발송
- 수신: `hsj0358@gmail.com`
- 제목: `HR·HRD 주간 브리핑 — YYYY.MM.DD`
- 본문: **이번 주 한눈에(TL;DR)** + 주제별 한 줄 요약 + **아티팩트 링크** + 실행 제안 요약
  (가독성을 위해 `htmlBody`/HTML로 서식 있는 본문 작성)
- **발송 절차 (순서대로 시도)**:
  1. **SMTP 자격증명이 있으면 자동 발송** — 환경변수 `GMAIL_SMTP_USER` /
     `GMAIL_SMTP_APP_PASSWORD`가 설정돼 있으면 `smtp.gmail.com:465`(SSL)로 발송
     (curl 등 사용). Gmail 앱 비밀번호 방식. **주간 자동 세션에서의 기본 경로.**
  2. **Gmail 도구가 있으면 활용** — send 계열 도구가 보이면 발송,
     `create_draft`만 있으면 초안 생성 (트리거로 뜬 세션에는 Gmail 커넥터가
     전달되지 않으므로 보통 이 경로는 없음).
  3. **둘 다 없으면 폴백** — 이메일 본문(HTML)을 `briefing/outbox/YYYY-MM-DD-email.html`로
     저장·커밋하고, 마지막 보고와 완료 알림에 "이메일 미발송 — outbox 확인"을 명시한다.
- 어떤 경로로 발송/폴백했는지 세션 마지막 보고에 명시한다.

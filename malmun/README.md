# 말문 영어코치

AI 코치와 1:1로 영어회화를 연습하는 모바일 웹앱. Claude 아티팩트로 게시돼 있다.

- 앱 주소: https://claude.ai/artifact/3ZXyr5ctuNwMHs9Q29LMQ9 (기본 비공개 · 공유 메뉴에서 공개 범위를 정한다)
- 소스: `index.html` 한 파일. 아티팩트 게시 형식이라 `<!doctype>`·`<head>` 가 없다 (게시할 때 붙는다).

`toto/`·`briefing/` 과 코드·설정·의존성을 하나도 공유하지 않는 별개 프로젝트다.

## 무엇을 하나

| 화면 | 내용 |
|---|---|
| 첫 안내 | 처음 열면 레벨 → 목표(추천 코치) → 하루 목표·공부 방법 세 단계. 건너뛸 수 있고 설정에서 다시 볼 수 있다 |
| 홈 | 오늘의 목표(분)·연속 학습일, 멈춘 수업 이어 하기, 오늘 복습할 문장, 현재 코치·레벨, 주제 10개, 나의 기록, 최근 학습 내역 |
| 코치 선택 | 5명 — 루미(왕초보 마스코트)·해나(자신감)·올리비아(비즈니스·면접)·제이크(캐주얼)·올리버(영국 영어). 목소리 미리 듣기 |
| 대화 | 코치가 영어로 질문(다시 듣기·천천히·해석·지난 대화) → 말이나 키보드로 대답 → 틀린 표현은 **힌트를 보고 먼저 스스로 고쳐 말하기**(초급 이상) → 안 되면 `You should say, "…"` 로 교정 → 따라 말하기 채점 → 대답에 이어지는 다음 질문. 짧게 대답하면 한 가지 더 말하게 하는 질문이 온다 |
| 리포트 | 대화 시간·대답 수·영어로 말한 단어·교정 수, 지난 수업 대비 대답 길이, 레벨 제안, 코치 총평, 교정 피드백(바뀐 단어 표시·오류 유형·스스로 고치기 결과), 복습할 표현, 전체 대화, 기록 지우기 |
| 복습 | 교정한 문장·복습 표현이 1·3·7·14·30일 간격으로 돌아온다. 틀렸던 내 문장을 보고 고쳐 말하거나, 한국어 뜻을 보고 영어로 말한다. 놓치면 다음 날 다시 |
| 학습 내역 | 날짜별 수업 목록 |

주제 중 `영어 면접`·`쇼핑·환불` 은 코치가 면접관·매장 직원 역할을 하는 롤플레이다.

## 아티팩트 기능과 대체 경로

| 기능 | 쓰는 capability | 없을 때 |
|---|---|---|
| 대화·교정·총평 | `sample` (대화는 quick, 총평은 default 티어) | **연습 모드** — 준비된 질문과 모범 답안으로 진행, AI 교정 없음 |
| 코치 목소리 | `tts` (코치마다 다른 목소리) | 브라우저 음성(`speechSynthesis`), 그것도 없으면 자막만 |
| 말로 대답 | `dictation` (영어로 받아쓰기) | 키보드 입력. 휴대폰 키보드의 음성 입력은 그대로 쓸 수 있다 |
| 학습 기록 | `db` + `user` — `data/users/<id>/profile`·그 아래 `sessions`·`data/users/<id>/review`(복습 카드) | 이 브라우저의 `localStorage` |

- `dictation`·`tts` 는 Chromium 브라우저 탭과 데스크톱 앱에서만 열린다. Claude 모바일 앱에서는 키보드 입력과 브라우저 음성으로 돈다.
- AI 대화와 목소리는 **보는 사람의 Claude 사용량**을 쓴다. 첫 대답 때 허락을 묻는다.
- `data/users/<id>/` 는 사람마다 비공개다. 소유자도 남의 기록을 읽지 못한다.
- 진행 중인 수업은 이 브라우저에만 저장된다(12시간). 새로 고침이나 앱 전환 뒤 홈에서 이어 하거나 거기까지로 리포트를 만든다.
- 앱은 승패나 점수를 지어내지 않는다. 따라 말하기·스스로 고치기·복습은 목표 문장과의 단어 일치율(85% 이상)로만 판정한다. 발음·유창성·의미가 맞는지는 재지 않으며, 모든 단어가 같을 때만 "정확해요" 라고 쓴다. 키보드로 적은 것도 같은 기준이다. 복습에서는 학습자가 "내 말도 맞아요" 로 판정을 뒤집을 수 있다.
- 레벨은 제안만 한다(대답 5개 이상인 최신 수업에서 교정 비율·대답 길이를 보고). 바꾸는 것은 학습자다.

## 학습 설계의 근거

- **스스로 고치기** — 교정 문장을 바로 주는 것(recast)보다 힌트로 스스로 고치게 하는 것(prompt)이 교실 연구 메타분석에서 효과가 더 컸다 (Lyster & Saito 2010, 교실 연구 15편). 이 앱의 AI 힌트가 같은 효과를 낸다는 직접 증거는 아니다. 왕초보는 부담이 커서 끄고, 한국어 대답·문장 조각에도 쓰지 않는다.
- **간격 복습** — 간격을 두고 다시 꺼내는 연습은 L2 어휘 기억에 작거나 중간 크기의 효과가 있다 (Kim & Webb 2022). 말하기 자체에 대한 근거는 더 적어서, 이 앱은 기억 유지 효과를 장담하지 않는다.
- **더 길게 말하기** — 짧은 대답 뒤에는 이유·예시를 묻는다(pushed output). 리포트는 대답 하나의 평균 영어 단어 수로 그 변화를 보여 준다.

## 고치고 다시 게시할 때

같은 아티팩트 주소를 유지하려면 `index.html` 을 고친 뒤 Artifact 도구에 이 파일과 위 URL 을 넘겨 다시 게시한다.
capability 를 바꿀 때만 `capabilities` 를 다시 적는다(생략하면 기존 선언이 그대로 간다).

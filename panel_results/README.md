# panel_results — 클로드 채팅에서 받은 Panel Result 를 넣는 곳

메뉴 **[4] 패널 결과 반영 및 리포트 생성** 이 이 폴더를 봅니다.

```
panel_results/
  260052_panel_result.json     ← 여기에 넣으세요
```

## 어떻게 만드나

1. 메뉴 `[3] 패널 자료 내보내기` 로 `reports/panel_<회차>/` 를 만듭니다.
2. `01_채팅에_적을_말.md` 를 따라 클로드 채팅에서 1·2·3단계를 돌립니다
   (단계마다 대화 하나 · 자료 파일이 여러 개여도 한 대화에 함께 첨부).
   3단계에는 `03_사회자자료.md` 와 `04_PanelResult_JSON_규격.md` 를
   **함께** 첨부합니다.
3. 3단계가 끝난 **같은 대화에서** 그 파일의 마지막 절
   "3단계 직후 — Panel Result JSON 파일 만들기" 블록을 보냅니다.
   규격 문서가 그 대화에 이미 있으므로 계약대로 만들어집니다.
4. 받은 `<회차>_panel_result.json` 을 이 폴더에 넣습니다.
5. 메뉴 `[4]` 를 고릅니다. 검증 → 가져오기 → 감사 → 리포트 갱신이 한 번에
   끝나고, 저장된 회차 분석이 있으면 **다시 수집하지 않습니다.**

## 파일을 지우지 않습니다

가져오기가 끝나도 원본 JSON 은 그대로 둡니다. 나중에 다시 감사할 수 있는
원자료이기 때문입니다.

```
python -m toto --round 260052 --audit-panel-result panel_results/260052_panel_result.json
```
